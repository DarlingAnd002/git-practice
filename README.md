# V0.2 使用说明

Java Swing 图形界面购物系统。需要 JDK 17 或以上，无第三方依赖。

## 本次更新

- 登录、注册和角色操作使用 Swing 图形界面，密码显示星号。
- 自动分配商品编号，支持销售者下架自己的商品。
- 结账可确认删除售完或下架项，保留订单和库存检查。
- 删除全部优惠及实例锁，使用本地明文数据。

## 启动

在 IDEA 中打开项目，运行 src/Main.java。运行配置的 Working directory 设置为项目根目录，以读取原有 data 文件夹。

也可以在项目目录打开 PowerShell：

    .\run.ps1

启动后直接显示登录窗口，不需要在控制台输入。

## 登录和注册

登录页输入账号和密码，按登录按钮，系统自动识别账号角色。
注册页填写账号、密码、确认密码，并选择消费者或销售者。
密码框输入时显示 *。账号为 3–24 位英文字母、数字或下划线，不区分大小写；密码为 8–128 位，区分大小写并保留空格。
注册成功后切回登录页。错误密码、重复账号和两次密码不一致会显示提示。
退出登录返回登录窗口。同一次运行中，各消费者的购物车分别保留。

## 销售者

我的商品：只显示自己的商品，包含编号、名称、价格、库存和在售状态。
添加商品：填写名称、单价和初始库存。系统自动生成编号，如 P001，下架后编号不复用。
修改价格：先选中商品，再输入新价格。历史订单不变。
设置库存：先选中商品，再设置新的总库存，不是在旧库存上增加。
下架商品：选中并确认，下架后不再出现在消费者商品列表中。库存、购物车项和历史订单不删除。
销售订单：只显示自己商品的买家、数量、成交价格和实收金额。

## 消费者

商品：选中商品，点击加入购物车并输入数量。重复添加会累加。
购物车：显示商品、数量、小计、当前库存和状态。
修改数量：先选中购物车项，输入新的总数量；0 表示删除。
删除选中商品：只移除自己的购物车项，不删除商店商品。
购买记录：只显示当前账号的已完成订单。

两个角色均有刷新、操作说明和退出登录按钮。
刷新会更新商品、库存和订单。操作说明会解释当前角色各项按钮的用法。

## 结账

每种商品在购物车中最多 99 件，且加购数量不能超过当前库存。
加购不占库存；其他消费者买完商品后，再刷新会显示 Sold out，原购物车项保留。
下架商品在已有购物车中标为已下架，不能继续购买。
点击结账时，先列出全部售完和下架项，询问是否一起删除。
同意后删除这些项并继续结算剩余商品；不同意则保持购物车不变。
删完购物车为空时只提示，不生成订单。数量超过剩余库存时，需调整数量或删除后重试。

应付金额等于成交单价乘数量之和，没有折扣。
最终确认窗口列出商品和金额；点击确认后重新校验价格、库存和购物车归属，保存订单并扣减库存，再清空购物车。
取消购买不会扣库存或记订单。已确认删除的售完、下架项不会因随后取消购买而恢复。
保存失败时不部分扣库存、不生成订单、不清空剩余购物车。

## 数据

    data/users.properties   账号、角色和明文密码
    data/store.properties   商品、归属、价格、库存、上架状态和订单

旧账号和旧商品文件继续读取。旧账号首次成功登录后会改存明文密码。
账号、商品和订单重启后保留；购物车重启后清空。历史订单按成交时金额保存，不会重新计算。
新商店没有预设账号和商品，先注册销售者并添加商品。
按当前约定，由使用者保证一次只运行一个实例。结账不连接真实支付，没有退款和物流功能。
data 目录和 build 目录已被 Git 忽略。

    New-Item -ItemType Directory -Force build
    javac --release 17 -encoding UTF-8 -d build src/Main.java src/shop/*.java test/shop/*.java
    java -cp build Main
