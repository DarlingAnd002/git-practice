# 购物系统 V0.6


运行环境与启动

使用 JDK 17 或更新版本，无第三方依赖。请在项目根目录运行：

    .\run.ps1

测试：

    .\run.ps1 -Test

没有脚本权限时可手动运行：

    New-Item -ItemType Directory -Force build
    javac --release 17 -encoding UTF-8 -d build src/Main.java src/shop/*.java
    java -cp build Main

界面与帮助

基础界面采用“中文（English）”：登录、注册、角色、页签、按钮、表单字段、筛选、订单表头和商品状态都有括号内英文。商品名称、账号、编号等业务数据按原内容显示；具体校验错误主要使用中文。

页面右上角的“？”表示当前页面帮助。点击后根据当前页签显示说明，不再一次堆出整个角色的全部功能。登录和注册分别说明账号规则、密码输入与角色选择；销售者的我的商品与销售订单分别说明管理和订单操作；消费者的商品、购物车、购买记录分别说明购买流程。帮助内容包含中文及括号内英文，可滚动阅读。

添加商品、编辑商品、批量加购、商品详情、购物车条目、图片管理和订单详情窗口也提供“？”，解释当前操作、默认值、保存方式和注意事项。大图预览保持纯图片，无工具栏和帮助文字；查看方式在商品页帮助中说明。

账号与角色

账号为 3–24 位字母、数字或下划线，密码为 8–128 位，注册时两次密码须相同。选择消费者或销售者，登录后按账号角色进入对应页面。密码框显示 *。

消费者可以浏览和购买商品、管理自己的购物车、查看自己的购买记录。销售者只能管理自己的商品和查看自己的销售订单。

销售者使用方法

添加商品时填写名称、正数价格和库存，商品编号自动分配。库存为 0 时显示售罄（Sold out）。

单击商品条目或复选框选中，支持直接鼠标多选。双击条目编辑名称、价格和库存，也可下架或重新上架；勾选多件后可批量上下架。所有操作先检查归属和数据，不能修改其他销售者的商品。

下架保留编号、库存、图片及历史记录。重新上架时可同时保存编辑内容。搜索支持名称、编号和销售者，状态筛选支持在售、已下架及售罄。

商品图片

每件商品支持一张主图。新增后可上传，已有商品双击编辑后可选择、更换、删除图片。只支持 PNG、JPG/JPEG，文件最大 10 MB，总像素最大 1200 万。

图片操作单独立即保存，取消编辑窗口不会撤销已保存的图片操作。上传失败保留旧图。图片复制到 data/images/商品编号.png，原文件移走后仍能显示。上下架及重启保留图片。

新上传图片保留原始分辨率，以 PNG 保存，缩略图单独生成并适配高分屏。旧版本曾缩小保存的图片无法恢复细节，请重新上传原图。无图或损坏时显示“暂无图片（No image）”，不影响购买。

商家和消费者商品列表、消费者购物车、商品详情均显示图片。单击图片打开无边框独立预览，不影响商品勾选。窗口按图片比例居中，大图最大为屏幕可用区域的 80%，同时不超过 1000 × 760；小图按原始像素显示，不全屏。

滚轮缩放，按住左键拖动，双击切换适应窗口和原始像素大小。点击预览外或切换窗口自动关闭；仅移开鼠标不会关闭。Esc 和右键也可关闭。

消费者使用方法

搜索、筛选商品，单击条目或复选框勾选。双击条目查看详情，可加入购物车或立即购买。勾选多件后可批量加入购物车，全部通过库存检查才一起加入。

购买数量默认 1，点击输入框清空便于重填，留空仍使用默认值。单项数量最多 99，并受库存限制。立即购买只处理当前商品，不影响已有购物车。

购物车与结账

购物车按商家分组，支持逐项勾选、商家组内全选和全部选择。组内小计与底部总额只统计勾选商品，底部结账栏固定可见。

数量可用加减按钮，也可点击中间数字输入。购物车留空保留当前数量，回车或移开焦点生效。错误或超库存输入保留并提示，已选项数量错误时禁止结账。右侧删除移除单件，底部删除勾选商品移除多件。

加入购物车不会预留库存。其他客户购买后，自己的购物车会按最新库存显示售罄或库存不足。售罄和下架项不自动删除，禁止购买及修改数量；结账时列出这些商品，客户同意才删除并继续，不同意返回。库存不足但仍有货时需要先减少数量。

结账只购买勾选商品，最终提交重新检查库存和价格。不同商家生成独立订单号，同一商家的多件商品合为一单。所有库存和订单一次保存，失败不部分成交。确认或取消时不误删其他购物车商品。

订单

客户购买记录、销售者销售订单显示时间、买家、商家、数量、金额和商品摘要。点击表头排序，双击查看完整明细；缩短的订单号可悬停查看。时间使用北京时间。

历史订单保留成交时名称、价格和数量，后续改名、改价、上下架不改变历史。旧版本已保存的合并订单不追溯拆分。

数据与范围

    data/users.properties    账号、角色和明文密码
    data/store.properties    商品、归属、库存、上下架状态和订单
    data/images/             商品主图

备份时一起备份整个 data 目录。旧账号和业务数据继续读取。账号、商品、图片和订单重启后保留；购物车、勾选状态和未完成输入只在当前运行期间保留。退出登录保留本次运行的实际购物车，放弃未生效的错误数量输入。

由使用者保证一次只运行一个实例。没有实例锁、优惠码、真实支付、退款及物流功能。data、build、out 和 IDE 本地配置不提交仓库。

学生九折

在结账确认窗口勾选“我是学生，享九折（Student: 10% off）”，本次购买按原价的 90% 结算，默认不勾选。学生身份由客户自行声明，未连接学籍验证。购物车结账和立即购买均可使用，取消购买不改变库存或订单，下次结账仍默认原价。
每个商品条目的原价小计乘以 0.90，四舍五入到分后汇总；商家小计、总实付和历史订单保存相同的折后金额，商品单价仍保留原价。结账确认显示原价、学生优惠及实付，订单详情显示优惠与实付。没有新增其他折扣规则。
增加 16 项自动检查，覆盖原价、九折、分币舍入、商家拆单、持久化、伪造报价与价格变化检查。

模拟支付网关

结账确认后打开模拟支付窗口，支持微信/支付宝演示二维码和银行卡测试表单。二维码只编码 DEMO 与 NO_REAL_PAYMENT 演示文字，不含真实付款链接，不会向微信或支付宝发起交易。
银行卡只接受测试卡号 4111 1111 1111 1111、5555 5555 5555 4444；填写测试姓名、未过期的 MM/YY 和任意三位数字 CVV。程序验证格式、Luhn 校验位、有效期及测试卡号，不连接银行。请勿输入真实银行卡信息。所有输入关闭时清空，不写入文件。
模拟成功才扣库存并按商家生成订单。模拟失败、取消、Esc 或关闭窗口不会成交；可重新结账。最终库存或订单保存失败时模拟支付作废。模拟流水仅在成功提示中显示，不作为真实支付凭证。学生九折后的实付金额直接传入支付窗口。
支付窗口的“？”提供对应操作帮助。新增 PaymentGateway.java、DemoPaymentDialog.java、DemoQrIcon.java 和 PaymentTest.java；运行仍只需要 JDK，无额外依赖。
