# v0.3 使用说明

Java Swing 图形界面购物系统，JDK 17 或以上，无第三方依赖。

## v0.3 更新摘要

1. 商品和购物车改为白底条目列表，使用左侧复选框多选，价格突出显示。
2. 单击勾选、双击打开操作窗口，删除底部重复的编辑、改价、改库存按钮。
3. 购物车增加可手动输入的数量框及加减按钮；留空保留默认值，超库存时保留错误输入并阻止结算。
4. 支持勾选结账、全选、单独购买和部分购买，未购买的商品继续保留。
5. 商品名称、价格和库存可一次修改，支持下架后重新上架及批量上下架。
6. 增加批量加购、批量删除、搜索筛选、订单列表和双击订单详情。
7. 输入出错时表单不关闭；刷新保留勾选、数量错误输入和滚动位置。
8. 同步操作说明和测试，旧账号、商品及历史订单文件继续使用。

详细更新记录见 CHANGELOG.md。

## 启动

在 IDEA 中运行 src/Main.java，Working directory 设置为项目根目录，读取原有 data 文件夹。
也可以在项目目录打开 PowerShell：

    .\run.ps1

启动后显示登录窗口，不在控制台输入。

## 登录和注册

登录时输入账号和密码，系统自动识别角色。注册时填写账号、两次密码并选择消费者或销售者。
账号为 3–24 位英文字母、数字或下划线，不区分大小写；密码为 8–128 位，区分大小写并保留空格，界面显示 *。
注册错误时保留输入，成功后清空密码并回到登录页。

## 商品列表与鼠标操作

商品和购物车使用白底条目列表，左侧是复选框，商品名称、编号、销售者及库存显示在中间，价格突出显示。
没有图片的商品使用统一占位图，不影响购买。
直接用鼠标点击左侧小框即可分别勾选多个商品，不需要 Ctrl 或 Shift。
单击条目空白处也可切换勾选；双击商品条目打开该商品的操作窗口。
点击数量、加减按钮、删除按钮不会打开商品操作窗口。

商品页的全选当前列表只影响当前搜索或筛选结果，已勾选的其他商品不会被自动取消。
上方显示总勾选数；批量上下架确认会列出将处理的商品，包含暂时被筛选隐藏的勾选项。
底部不再重复显示编辑商品、修改价格、设置库存等单件操作按钮。

## 销售者

双击自己的商品，直接修改名称、价格和库存，或上架、下架。
添加商品只输入名称、价格和初始库存，编号自动生成，下架不回收编号。
库存表示当前可售总数量，不是在原库存上增加，范围为 0–1000000。
下架保留原编号、库存和历史订单；消费者列表不再显示该商品，原购物车中仍保留并标记已下架。
重新上架同时保存当前修改。库存为 0 也可上架，但仍是 Sold out，补货后才能购买。
勾选多件商品后，顶部出现批量上架或批量下架按钮。确认后一起保存，越权或保存失败时不会只改其中一部分。
销售者只能修改自己的商品，只能查看自己售出的商品明细和实收。

## 消费者

双击商品进入详情，可输入数量、加入购物车或立即购买。
也可直接勾选多件商品，再点击上方加入勾选商品，设置每种商品加入的数量。
批量加购时全部通过库存检查后才修改购物车，任一商品不足或售完则不部分加入。
加购不占库存，重复加购会累加，每种商品累计最多 99 件且不能超过当前库存。
新加入的商品默认在购物车中勾选；立即购买独立结算，不清空原购物车。

## 购物车数量与删除

每个商品右侧显示“− / 数量 / +”。数量中间可以直接点击、手动输入，不是只能点加减。
点入数量框会清空原数字；改完按回车或移开焦点生效。留空保留原数量。
新增加购的数量默认 1；已有购物车项显示当前数量。手动输入 2 就是 2，不会拼到原数字前面。
输入 0 表示删除该项。减号在数量为 1 时禁用，加号达到库存或 99 件限制时禁用。
输入非法数字或超库存时保留原输入并显示错误，不修改购物车实际数量；勾选项存在输入错误时禁止结算。

右侧删除用于移除单个条目；底部删除勾选商品用于批量删除。两者都需要确认。
双击购物车条目仍可打开详细窗口，修改数量、删除或单独购买一部分。
单独购买成功后只减少买走的数量，其余项保留。取消购买不改数量。
售完或下架商品保持原数量、显示 Sold out 或已下架，数量输入和加减按钮禁用，只能删除或保留。

## 勾选结账

底部全选可以一次勾选整个购物车；金额和件数实时按复选框计算。
结算勾选商品只购买已勾选项，没有勾选时按钮禁用。
未勾选的商品不会被购买，未勾选的售罄项不会阻止购买其他商品，也不会被删除。
勾选项中若有售完或下架商品，会列出并询问是否删除。拒绝则不删除、不购买；同意后删除这些项再继续。
有货但数量不足时，需修正数量或删除；系统不自动减少购买数量。
最终确认前显示商品和金额，确认时再次校验价格、库存和归属。
应付金额为成交单价乘数量之和，没有优惠。保存成功后才扣库存、记录订单并移除已买商品。
取消或保存失败不会部分扣库存、记半笔订单或清空其他商品。
已明确同意删除的售完或下架项不会因后续取消购买而恢复。

## 搜索、筛选与刷新

搜索支持商品名称、编号和销售者账号的部分匹配，不区分英文字母大小写。
销售者可筛选全部、在售、已下架、售罄；消费者可筛选全部、有货、售罄。
刷新保留仍然存在商品的勾选与列表滚动位置。订单列表保留选中项和排序。
操作说明按钮解释当前角色的使用方法。退出登录保留本次运行中各账号自己的购物车及勾选状态。

## 表单与订单

添加商品、编辑商品、批量加购和数量表单出错时窗口不关闭，原内容保留，错误显示在窗口内。
名称和价格有误会标红，可直接修改重试；取消、关闭窗口或 Esc 放弃操作。
订单使用简洁表格，双击查看成交明细。消费者只看自己的订单，销售者只看自己的商品与实收。
后续改名、改价、下架不改变历史订单。时间按北京时间显示。

## 数据与范围

    data/users.properties   账号、角色和明文密码
    data/store.properties   商品归属、价格、库存、上架状态和订单

原账号和数据继续使用。旧账号首次成功登录后改存明文密码。
账号、商品和订单重启后保留；购物车、勾选和未完成输入在程序退出后不保存。
同一运行期间刷新保留数量错误输入；退出登录会放弃未生效的错误输入，保留实际购物车数量。
由使用者保证一次只运行一个实例。没有实例锁、真实支付、退款、物流功能。
data、build、out 和 IDEA 本地配置不要提交仓库。

    .\run.ps1 -Test

279 项自动检查：购物规则 19、账号角色 27、库存订单 54、共享库存购物车 59、编号上下架 35、数字输入 18、商品编辑单独购买 25、勾选结账 21、批量条目操作 19。
另验证 43 项条目界面操作，包括直接鼠标多选、手动数量、加减、输入错误保留、批量上下架与加购、单件和批量删除、售罄处理及勾选结账。

无脚本权限时可手动编译启动：

    New-Item -ItemType Directory -Force build
    javac --release 17 -encoding UTF-8 -d build src/Main.java src/shop/*.java test/shop/*.java
    java -cp build Main
